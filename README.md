เครื่องมือรีจอย Roblox อัตโนมัติสำหรับ UG Phone + Termux (ใช้กับบัญชีและเครื่องของตัวเองเท่านั้น)

## 1. ติดตั้ง (ทำตามลำดับ)

### ขั้นที่ 1 — เลือก mirror ของ Termux
```
termux-change-repo
```
เลื่อนด้วยปุ่มลูกศร กด Space เลือก "Single mirror" (หรือ Mirror group) → เลือก mirror ที่ใกล้ (เช่น Singapore / Asia) → OK
ถ้าข้ามขั้นนี้แล้ว `pkg update` ช้าหรือ error 404 ให้กลับมาทำใหม่

### ขั้นที่ 2 — ติดตั้งด้วยคำสั่งเดียว
```
curl -Ls https://raw.githubusercontent.com/Garnt024020806/TOOL/main/setup.sh | bash
```
สคริปต์ทำตามลำดับ: `termux-setup-storage` → `pkg update/upgrade` → `python`, `python-pip`, `tsu`, `libexpat`, `openssl` → `pip install -r requirements.txt` → ดาวน์โหลด `rejoin.py` ไปที่ `/sdcard/Download/rejoin.py` (และสำเนาที่ `~/rejoin.py`)

- หน้าต่างขอสิทธิ์ที่เก็บข้อมูลจะเด้งขึ้นทันทีที่เริ่ม → กด **อนุญาต** ให้เร็ว (ก่อนสคริปต์ไปถึงบรรทัดดาวน์โหลดไฟล์) ถ้ากดช้าให้รันคำสั่งติดตั้งซ้ำอีกรอบ
- ถ้า `pkg upgrade` ถามอะไร สคริปต์ตอบ yes ให้แล้ว รอจนจบ

### ขั้นที่ 3 — ตั้งค่าสิทธิ์ Android / Termux และวิธีเช็ก

| สิทธิ์ | วิธีตั้ง | วิธีเช็กว่าผ่าน |
|---|---|---|
| ที่เก็บข้อมูล | ตั้งค่า > แอป > Termux > สิทธิ์ > ไฟล์และสื่อ/ที่เก็บข้อมูล = อนุญาต (หรือรัน `termux-setup-storage`) | `touch /sdcard/Download/t && rm /sdcard/Download/t` ต้องไม่มี error |
| ปิดการประหยัดแบตเตอรี่ | ตั้งค่า > แอป > Termux > แบตเตอรี่ = **ไม่จำกัด / ไม่เพิ่มประสิทธิภาพ** (ทำกับ Roblox ทุกตัวที่โคลนด้วย) | ตั้งค่า > แบตเตอรี่ > การเพิ่มประสิทธิภาพ ต้องไม่มี Termux/Roblox อยู่ในรายการที่ถูกจำกัด |
| สิทธิ์รูท | เปิดรูทให้เครื่อง UG Phone แล้วรัน `su` ครั้งแรก กด **Grant/อนุญาต** ให้ Termux ในแอปจัดการรูท (Magisk/KernelSU) | `su -c id` ต้องขึ้น `uid=0(root)` |
| แสดงทับแอปอื่น (โหมดไม่รูท) | ตั้งค่า > แอป > Termux > แสดงทับแอปอื่น = อนุญาต | ถ้าไม่ได้ จะสั่งเปิดเกมจาก Termux ไม่ได้ในโหมดไม่รูท |
| ล็อก Termux ไว้ในหน้าล่าสุด | ดึงแถบแจ้งเตือน Termux กด "Acquire wakelock" หรือให้โปรแกรมทำเอง (ตั้งค่าอัตโนมัติ > Wake-lock) | แถบแจ้งเตือน Termux ขึ้น "wake lock held" |

### ขั้นที่ 4 — รันโปรแกรม (โหมดรูท)
```
su -c "export PATH=$PATH:/data/data/com.termux/files/usr/bin && export TERM=xterm-256color && cd /storage/emulated/0/Download && python ./rejoin.py"
```
โหมดไม่รูท (หรือรันจาก `~`):
```
cd ~ && python rejoin.py
```
โปรแกรมตรวจโหมดเองด้วย `su -c id` — ไม่ต้องบอกว่าจะรันแบบไหน

## 2. วิธีใช้

1. เมนู **3** ตั้งลิงก์เกม (รองรับ Place ID, `roblox.com/games/...`, ลิงก์ private server, ลิงก์แชร์, `roblox://...`) และปรับช่วงตรวจสอบ/หน่วงการเปิด
2. เมนู **4** สแกนแพ็กเกจ `com.roblox.*` แล้วเลือกตัวที่จะรัน (`1,3` หรือ `all`)
3. (ไม่บังคับ) เมนู **5** ใส่คุกกี้ใน `cookie.txt` แล้วล็อกอิน
4. เมนู **6** ปรับระบบอัตโนมัติ, เมนู **7** ตั้ง Discord webhook
5. เมนู **1** เริ่มรีจอย — กด `Ctrl+C` เพื่อหยุดและกลับเมนู

### พฤติกรรมหลัก
- เปิดอินสแตนซ์ทีละตัวห่างกัน 15 วินาที (ใช้กับทั้งตอนเริ่มและตอนรีจอยกลางทาง)
- ตรวจทุก 30 วินาที — หลุดแล้วรอ 10s → 20s → 40s … สูงสุด 300s ก่อนรีจอย และรีเซ็ตเมื่อเสถียรต่อเนื่อง 5 นาที
- หลังเปิดแอปมีช่วงรอเข้าเกม 90 วินาที (ปรับได้ที่เมนู 6) ระหว่างนี้ไม่นับว่าหลุด

### รูท vs ไม่รูท
| ความสามารถ | รูท | ไม่รูท |
|---|---|---|
| ตรวจโปรเซสแอป | ✅ | ⚠️ ตรวจไม่ได้บนเครื่องส่วนใหญ่ |
| ตรวจแอปอยู่หน้าจอ | ✅ (ปิดเป็นค่าเริ่มต้น) | ❌ |
| Force-stop ก่อนเปิดใหม่ | ✅ | ❌ |
| แคปหน้าจอ / แนบ webhook | ✅ | ❌ |
| ใส่คุกกี้ลงแอป | ✅ | ❌ (ตรวจความถูกต้องของคุกกี้ได้) |
| ตรวจ "อยู่ในเกม" ผ่าน Roblox API | ✅ ถ้ามีคุกกี้ | ✅ ถ้ามีคุกกี้ |

โหมดไม่รูทที่ไม่มีคุกกี้จะแสดง "ไม่ทราบสถานะ" — ใช้เมนู 6 ตั้ง "รีจอยตามเวลา (นาที)" แทน

### Heartbeat (สคริปต์ในเกม)
สคริปต์ Lua ที่รันในเกมส่งสัญญาณมาที่เครื่องมือ (`127.0.0.1` ในเครื่องเอง) ทุก 15 วินาที ทำให้รู้ว่าอินสแตนซ์ "เล่นอยู่จริง" โดยไม่ต้องใช้รูทหรือคุกกี้ สคริปต์จะ **หยุดส่ง** เมื่อเฟรมเกมค้างเกิน 5 วินาที หรือมีหน้าต่าง Disconnected/Error ขึ้น

วิธีติดตั้ง:
1. เมนู 6 > Heartbeat > กด 5 เพื่อสร้างไฟล์ `.lua` ต่ออินสแตนซ์ (แต่ละไฟล์ตั้ง `ID` เป็นชื่อแพ็กเกจของโคลนนั้นไว้แล้ว)
2. คัดลอกไฟล์ของแต่ละโคลนไปไว้ในโฟลเดอร์ autoexec ของเอ็กซิคิวเตอร์ในโคลนนั้น หรือรันตอนเข้าเกม
3. เมนู 6 > Heartbeat > กด 1 เปิดใช้งาน แล้วเริ่มรีจอยที่เมนู 1

พฤติกรรม: ถ้าเงียบเกิน 90 วินาที (ปรับได้) หรือไม่มีสัญญาณหลังรีจอยเกินเวลารอเข้าเกม จะรีจอยพร้อม backoff ตามปกติ ถ้ายังไม่เคยได้รับสัญญาณจากอินสแตนซ์นั้นเลย เครื่องมือจะใช้วิธีตรวจแบบเดิมแทน (ไม่รีจอยวน) และแสดงใน "รายละเอียด"

ข้อควรรู้: ต้องใช้เอ็กซิคิวเตอร์ที่เรียก HTTP ไป `127.0.0.1` ได้ และการใช้เอ็กซิคิวเตอร์ขัดกับกฎของ Roblox อาจทำให้บัญชีถูกแบน — ตัดสินใจและรับความเสี่ยงเอง ทดสอบตัวรับสัญญาณได้ด้วย `curl http://127.0.0.1:8765/ping` (ต้องตอบ `pong` ขณะกำลังรีจอยอยู่)

### เรื่องคุกกี้ (cookie.txt)
- 1 บรรทัด / 1 บัญชี จับคู่กับอินสแตนซ์ที่ตรวจพบตามลำดับ (บรรทัดแรก = แพ็กเกจแรก) บรรทัดว่างและบรรทัดที่ขึ้นต้นด้วย `#` ถูกข้าม
- โปรแกรมแสดงคุกกี้แบบซ่อนเสมอ ไม่เขียนลงล็อก ไม่ส่งเข้า webhook ไม่เก็บใน `config.json`
- **ห้ามแชร์ไฟล์นี้หรือส่งต่อให้ใคร** — ใครได้คุกกี้ไปเข้าบัญชีคุณได้ทันที
- การใส่คุกกี้เขียนลงฐานข้อมูลคุกกี้ของแอป (`app_webview/.../Cookies`) ขึ้นกับเวอร์ชัน Roblox/โคลน ถ้าไม่สำเร็จให้ล็อกอินในแอปด้วยตัวเองหนึ่งครั้ง

## 3. แก้ปัญหาที่เจอบ่อย

| อาการ | วิธีแก้ |
|---|---|
| `ModuleNotFoundError: rich` / `requests` | `pip install -r requirements.txt` (ถ้ารันผ่าน `su` แล้วยังไม่เจอ ให้ติดตั้งจาก Termux ปกติ ไม่ใช่ใน su) |
| `CANNOT LINK EXECUTABLE` หรือ `libpython... not found` ตอนรันผ่าน `su` | เพิ่ม `export LD_LIBRARY_PATH=/data/data/com.termux/files/usr/lib &&` ก่อน `cd ...` ในคำสั่ง |
| `python: not found` ใน `su` | ตรวจว่ามี `export PATH=$PATH:/data/data/com.termux/files/usr/bin` ในคำสั่ง |
| โปรแกรมขึ้นว่าเป็น "ไม่รูท" ทั้งที่มีรูท | รัน `su -c id` เองใน Termux และกด Grant ในแอปรูท; ถ้าไม่ขึ้น `uid=0` แปลว่ายังไม่ได้ให้สิทธิ์ |
| "เขียน /sdcard/Download ไม่ได้" | อนุญาตสิทธิ์ที่เก็บข้อมูลให้ Termux แล้วรัน `termux-setup-storage` ใหม่ |
| ไม่พบแพ็กเกจ | เมนู 4 พิมพ์ชื่อแพ็กเกจเอง (คั่นด้วยคอมมา) หรือแก้ `package_prefix` ใน `config.json` |
| เปิดแอปได้แต่ไม่เข้าเกม (ขึ้น "ใช้ launcher แทน") | ลิงก์ไม่ถูกส่งเข้าแอปโคลน ลองใช้ Place ID ล้วน หรือลิงก์ `roblox://placeID=...` |
| รีจอยวนซ้ำทั้งที่อยู่ในเกม | ปิด "ตรวจว่าแอปอยู่หน้าจอ" (เมนู 6) เมื่อรันหลายอินสแตนซ์พร้อมกัน — มีแค่แอปเดียวที่อยู่หน้าจอได้ |
| คุกกี้ "หมดอายุ/ไม่ถูกต้อง" | ล็อกอินเว็บใหม่แล้วคัดลอก `.ROBLOSECURITY` ใหม่ (การออกจากระบบทำให้คุกกี้เก่าใช้ไม่ได้) |
| Heartbeat ไม่เข้า (รายละเอียดขึ้น "ยังไม่เคยได้ heartbeat") | เช็ก `ID` ในสคริปต์ตรงกับชื่อแพ็กเกจ, พอร์ตตรงกับเมนู 6 > Heartbeat, เอ็กซิคิวเตอร์อนุญาต HTTP ไป localhost, และเริ่มเมนู 1 แล้ว (ตัวรับเปิดเฉพาะตอนรีจอยทำงาน) |
| Webhook ส่งไม่ออก | เมนู 7 > 8 ส่งทดสอบ; URL ต้องขึ้นต้น `https://discord.com/api/webhooks/` |
| หน้าจอแสดงตัวอักษรเพี้ยน | ตั้ง `export TERM=xterm-256color` และใช้ฟอนต์ที่รองรับภาษาไทยใน Termux |
| ดูย้อนหลังว่าเกิดอะไรขึ้น | เปิดไฟล์ `/sdcard/Download/RejoinTool/logs/rejoin.log` |
