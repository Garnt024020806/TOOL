## 1. ติดตั้ง (ทำตามลำดับ)

### ขั้นที่ 1 — เลือก mirror ของ Termux
```
termux-change-repo
```
เลื่อนด้วยปุ่มลูกศร กด Space เลือก "Single mirror" (หรือ Mirror group) → เลือก mirror ที่ใกล้ (เช่น Singapore / Asia) → OK
ถ้าข้ามขั้นนี้แล้ว `pkg update` ช้าหรือ error 404 ให้กลับมาทำใหม่

### ขั้นที่ 2 — ติดตั้งด้วยคำสั่งเดียว
```
curl -Ls https://raw.githubusercontent.com/Garnt024020806/TOOL/main/setup.sh | bash
```
สคริปต์ทำตามลำดับ: `termux-setup-storage` → `pkg update/upgrade` → `python`, `python-pip`, `tsu`, `libexpat`, `openssl` → `pip install -r requirements.txt` → ดาวน์โหลด `rejoin.py` ไปที่ `/sdcard/Download/rejoin.py` (และสำเนาที่ `~/rejoin.py`)

- หน้าต่างขอสิทธิ์ที่เก็บข้อมูลจะเด้งขึ้นทันทีที่เริ่ม → กด **อนุญาต** ให้เร็ว (ก่อนสคริปต์ไปถึงบรรทัดดาวน์โหลดไฟล์) ถ้ากดช้าให้รันคำสั่งติดตั้งซ้ำอีกรอบ
- ถ้า `pkg upgrade` ถามอะไร สคริปต์ตอบ yes ให้แล้ว รอจนจบ

### ขั้นที่ 3 — ตั้งค่าสิทธิ์ Android / Termux และวิธีเช็ก

| สิทธิ์ | วิธีตั้ง | วิธีเช็กว่าผ่าน |
|---|---|---|
| ที่เก็บข้อมูล | ตั้งค่า > แอป > Termux > สิทธิ์ > ไฟล์และสื่อ/ที่เก็บข้อมูล = อนุญาต (หรือรัน `termux-setup-storage`) | `touch /sdcard/Download/t && rm /sdcard/Download/t` ต้องไม่มี error |
| ปิดการประหยัดแบตเตอรี่ | ตั้งค่า > แอป > Termux > แบตเตอรี่ = **ไม่จำกัด / ไม่เพิ่มประสิทธิภาพ** (ทำกับ Roblox ทุกตัวที่โคลนด้วย) | ตั้งค่า > แบตเตอรี่ > การเพิ่มประสิทธิภาพ ต้องไม่มี Termux/Roblox อยู่ในรายการที่ถูกจำกัด |
| สิทธิ์รูท | เปิดรูทให้เครื่อง UG Phone แล้วรัน `su` ครั้งแรก กด **Grant/อนุญาต** ให้ Termux ในแอปจัดการรูท (Magisk/KernelSU) | `su -c id` ต้องขึ้น `uid=0(root)` |
| แสดงทับแอปอื่น (โหมดไม่รูท) | ตั้งค่า > แอป > Termux > แสดงทับแอปอื่น = อนุญาต | ถ้าไม่ได้ จะสั่งเปิดเกมจาก Termux ไม่ได้ในโหมดไม่รูท |
| ล็อก Termux ไว้ในหน้าล่าสุด | ดึงแถบแจ้งเตือน Termux กด "Acquire wakelock" หรือให้โปรแกรมทำเอง (ตั้งค่าอัตโนมัติ > Wake-lock) | แถบแจ้งเตือน Termux ขึ้น "wake lock held" |

### ขั้นที่ 4 — รันโปรแกรม (โหมดรูท)
```
su -c "export PATH=$PATH:/data/data/com.termux/files/usr/bin && export TERM=xterm-256color && cd /storage/emulated/0/Download && python ./rejoin.py"
```
โหมดไม่รูท (หรือรันจาก `~`):
```
cd ~ && python rejoin.py
```
โปรแกรมตรวจโหมดเองด้วย `su -c id` — ไม่ต้องบอกว่าจะรันแบบไหน

## 2. วิธีใช้

1. เมนู **3** ตั้งลิงก์เกม (รองรับ Place ID, `roblox.com/games/...`, ลิงก์ private server, ลิงก์แชร์, `roblox://...`) และปรับช่วงตรวจสอบ/หน่วงการเปิด
2. เมนู **4** สแกนแพ็กเกจ `com.roblox.*` แล้วเลือกตัวที่จะรัน (`1,3` หรือ `all`)
3. (ไม่บังคับ) เมนู **5** ใส่คุกกี้ใน `cookie.txt` แล้วล็อกอิน
4. เมนู **6** ปรับระบบอัตโนมัติ, เมนู **7** ตั้ง Discord webhook
5. เมนู **1** เริ่มรีจอย — กด `Ctrl+C` เพื่อหยุดและกลับเมนู

### พฤติกรรมหลัก
- เปิดอินสแตนซ์ทีละตัวห่างกัน 15 วินาที (ใช้กับทั้งตอนเริ่มและตอนรีจอยกลางทาง)
- ตรวจทุก 30 วินาที — หลุดแล้วรอ 10s → 20s → 40s … สูงสุด 300s ก่อนรีจอย และรีเซ็ตเมื่อเสถียรต่อเนื่อง 5 นาที
- หลังเปิดแอปมีช่วงรอเข้าเกม 90 วินาที (ปรับได้ที่เมนู 6) ระหว่างนี้ไม่นับว่าหลุด

### รูท vs ไม่รูท
| ความสามารถ | รูท | ไม่รูท |
|---|---|---|
| ตรวจโปรเซสแอป | ✅ | ⚠️ ตรวจไม่ได้บนเครื่องส่วนใหญ่ |
| ตรวจแอปอยู่หน้าจอ | ✅ (ปิดเป็นค่าเริ่มต้น) | ❌ |
| Force-stop ก่อนเปิดใหม่ | ✅ | ❌ |
| แคปหน้าจอ / แนบ webhook | ✅ | ❌ |
| ใส่คุกกี้ลงแอป | ✅ | ❌ (ตรวจความถูกต้องของคุกกี้ได้) |
| ตรวจ "อยู่ในเกม" ผ่าน Roblox API | ✅ ถ้ามีคุกกี้ | ✅ ถ้ามีคุกกี้ |

โหมดไม่รูทที่ไม่มีคุกกี้จะแสดง "ไม่ทราบสถานะ" — ใช้เมนู 6 ตั้ง "รีจอยตามเวลา (นาที)" แทน

### สร้าง heartbeat.lua ลงโฟลเดอร์ autoexec ของ Delta อัตโนมัติ
เครื่องมือสร้าง/อัปเดต `heartbeat.lua` ที่ `/storage/emulated/0/Delta/Autoexecute/` ให้เองทุกครั้งที่เปิดโปรแกรม ทุกครั้งที่กดเริ่มรีจอย และเมื่อแก้พอร์ต/ความถี่ของ heartbeat ไม่ต้องคัดลอกไฟล์เอง
- ไฟล์อื่นในโฟลเดอร์ (เช่น `BSS.lua`) ไม่ถูกแตะ และถ้ามี `heartbeat.lua` ที่ไม่ใช่ของเครื่องมือจะข้ามไม่เขียนทับ
- ครั้งแรกที่สร้างไฟล์สำเร็จ จะเปิดใช้ heartbeat ให้ 1 ครั้ง (ปิดเองทีหลังได้ที่ เมนู 6 > Heartbeat > 1 และจะไม่ถูกเปิดซ้ำ)
- เปลี่ยนโฟลเดอร์ ปิด/เปิดการสร้างอัตโนมัติ หรือสั่งสร้างทันทีได้ที่ เมนู 6 > Heartbeat ข้อ 6, 7, 8 (ใส่ `{pkg}` ในพาธ ถ้าแต่ละโคลนมีโฟลเดอร์ autoexec แยกกัน จะสร้างให้ทีละโคลน)
- ไฟล์เดียวใช้ได้กับหลายโคลนที่ใช้โฟลเดอร์ร่วมกัน: ในโหมดรูท เครื่องมือดูว่าสัญญาณมาจากแอป (UID) ไหนผ่าน `/proc/net/tcp` แล้วจับคู่กับแพ็กเกจเอง ถ้าอ่านไม่ได้ จะจับคู่กับอินสแตนซ์เดียวที่รันอยู่ หรือจับคู่จากชื่อบัญชีเมื่อมีคุกกี้
- เปิดเกมใหม่ 1 ครั้งหลังสร้างไฟล์ เพื่อให้ Delta รันสคริปต์ตอนเข้าเกม

### Heartbeat (สคริปต์ในเกม)
สคริปต์ Lua ที่รันในเกมส่งสัญญาณมาที่เครื่องมือ (`127.0.0.1` ในเครื่องเอง) ทุก 15 วินาที ทำให้รู้ว่าอินสแตนซ์ "เล่นอยู่จริง" โดยไม่ต้องใช้รูทหรือคุกกี้ สคริปต์จะ **หยุดส่ง** เมื่อเฟรมเกมค้างเกิน 5 วินาที หรือมีหน้าต่าง Disconnected/Error ขึ้น

วิธีติดตั้ง:
1. เมนู 6 > Heartbeat > กด 5 เพื่อสร้างไฟล์ `.lua` ต่ออินสแตนซ์ (แต่ละไฟล์ตั้ง `ID` เป็นชื่อแพ็กเกจของโคลนนั้นไว้แล้ว)
2. คัดลอกไฟล์ของแต่ละโคลนไปไว้ในโฟลเดอร์ autoexec ของเอ็กซิคิวเตอร์ในโคลนนั้น หรือรันตอนเข้าเกม
3. เมนู 6 > Heartbeat > กด 1 เปิดใช้งาน แล้วเริ่มรีจอยที่เมนู 1

พฤติกรรม: ถ้าเงียบเกิน 90 วินาที (ปรับได้) หรือไม่มีสัญญาณหลังรีจอยเกินเวลารอเข้าเกม จะรีจอยพร้อม backoff ตามปกติ ถ้ายังไม่เคยได้รับสัญญาณจากอินสแตนซ์นั้นเลย เครื่องมือจะใช้วิธีตรวจแบบเดิมแทน (ไม่รีจอยวน) และแสดงใน "รายละเอียด"

ข้อควรรู้: ต้องใช้เอ็กซิคิวเตอร์ที่เรียก HTTP ไป `127.0.0.1` ได้ และการใช้เอ็กซิคิวเตอร์ขัดกับกฎของ Roblox อาจทำให้บัญชีถูกแบน — ตัดสินใจและรับความเสี่ยงเอง ทดสอบตัวรับสัญญาณได้ด้วย `curl http://127.0.0.1:8765/ping` (ต้องตอบ `pong` ขณะกำลังรีจอยอยู่)

### แผงสด + คอนโซลสั่งรีจอย (เมนู 1)
ระหว่างรัน แผงสดแสดงสถานะรายอินสแตนซ์ (สถานะ, เล่นมานานเท่าไร, ล้มเหลว/รีจอย, เวลาตรวจถัดไป, รายละเอียด) พร้อม RAM ว่างและโหลดเครื่อง เหตุการณ์ล่าสุดอยู่ด้านล่าง (ใหม่สุดอยู่บน) และมีช่อง **คอนโซล** ให้พิมพ์คำสั่งแล้วกด Enter ได้ทันที

| คำสั่ง | ทำอะไร |
|---|---|
| `rejoin 1` / `rejoin all` | บังคับรีจอยทันที (รูท: force-stop ก่อน) ข้าม backoff และไม่นับเป็นความล้มเหลว (ย่อ: `r`) |
| `pause 1` / `pause all` | หยุดดูแลอินสแตนซ์ชั่วคราว (ย่อ: `p`) |
| `resume 1` / `resume all` | กลับมาดูแลและรีจอยทันที |
| `status` | สรุปสถานะทุกอินสแตนซ์ |
| `ram` | ล้างแรมตอนนี้ (รูท) |
| `shot` | แคปหน้าจอ บันทึกในโฟลเดอร์ และส่งรายงานเข้า Webhook ถ้าตั้งไว้ (รูท) |
| `clear` | ล้างหน้าจอซ้อนแบบ force (รูท) |
| `help` / `quit` | ดูคำสั่ง / หยุดแล้วกลับเมนู (หรือกด Ctrl+C) |

เลขอินสแตนซ์คือเลขในคอลัมน์ `#` ซึ่งตรงกับเมนู 2 และลำดับคุกกี้ ส่วนเมนู **2** เป็นแผงสดเช่นกัน รีเฟรชอัตโนมัติ (กด Enter เพื่อกลับ)

### Console webhook (เมนู 7)
ส่งบันทึกคอนโซลทุกบรรทัด (เหตุการณ์, คำสั่งที่พิมพ์, ผลลัพธ์) เข้า Discord เป็นข้อความโค้ดบล็อก รวมส่งทุก 10 วินาที (ปรับได้ 3-300) ตั้ง URL แยกจาก Webhook หลักได้ ถ้าเว้นว่างจะใช้ URL หลัก ปิดอยู่เป็นค่าเริ่มต้น ค่าใน `config.json`: `console_webhook.enabled/url/flush_sec`
หมายเหตุ: Webhook ของ Discord ส่งข้อความออกได้อย่างเดียว สั่งงานจาก Discord กลับมาที่เครื่องมือไม่ได้ (ต้องทำเป็นบอท) ให้สั่งผ่านช่องคอนโซลในแผงสดแทน

### Disconnected / Error Code 277 (หลุดแล้วไม่รีจอย)
Roblox วาดหน้าต่าง Disconnected ในตัวเกมเอง Android จึงมองเห็นเป็นแอปที่ยังรันอยู่ปกติ — เวอร์ชันเก่าที่ไม่มีคุกกี้/heartbeat จึงรายงาน "ปกติ" ทั้งที่หลุดไปแล้ว เวอร์ชันนี้ตรวจหลุดได้ 3 ทาง (ใช้ร่วมกันได้):
1. **ตรวจจากภาพหน้าจอ (รูท, เปิดเป็นค่าเริ่มต้น)** — แคปหน้าจอแบบ raw แล้วหาแผงสี่เหลี่ยมสีเทาเข้ม (#393B3D) ที่มีปุ่มสีขาวอยู่ข้างใน ตรวจทุก 30 วินาที ต้องเจอติดกัน 2 รอบจึงรีจอย (กันตรวจพลาด) ตั้งค่าที่ เมนู 6 > หน้าจอ
2. **Heartbeat** — สคริปต์ในเกมส่งข้อความ error (เช่น Error Code 277) มาทันทีที่ขึ้นหน้าต่าง (ใช้ไฟล์ `.lua` ล่าสุด สร้างใหม่ที่เมนู 6 > Heartbeat > 5)
3. **คุกกี้ + Roblox API** — สถานะเปลี่ยนจากอยู่ในเกมเป็นออฟไลน์ ใช้ได้ทั้งโหมดรูทและไม่รูท

ข้อจำกัด: วิธีที่ 1 เห็นได้เฉพาะอินสแตนซ์ที่อยู่บนหน้าจอ (หน้าต่างที่โฟกัส) ถ้าเปิดหลายโคลนให้ใช้ร่วมกับวิธีที่ 2 หรือ 3 ถ้ารูปแบบหน้าต่างของ Roblox เปลี่ยนจนตรวจไม่เจอ ให้ลองเมนู 6 > หน้าจอ > 8 (ทดสอบตรวจ Disconnected ตอนนี้ ไม่ทำอะไร) ตอนที่หน้าต่างขึ้นอยู่

### ล้างหน้าจอซ้อน (เมนู 6 > หน้าจอ)
ตรวจทุก 60 วินาที (รูทเท่านั้น): ปิดหน้าต่างระบบที่ค้าง, force-stop แอปที่ขึ้นหน้าต่าง "has stopped / not responding" แล้วให้ระบบรีจอยเปิดใหม่, และ force-stop โคลนที่มี task ซ้อนกัน (ต้องเจอ 2 รอบติดกัน และเว้น 10 นาทีต่อแอป) ตัวเลือก "ปิดแอปแปลกปลอมที่ขึ้นทับหน้าจอ" ปิดอยู่เป็นค่าเริ่มต้น (ยกเว้น Termux/ระบบ/หน้าหลัก/Magisk) ถ้า force-stop โคลนที่ปกติโดยไม่ควร ให้ปิดข้อ "force-stop แอปที่มีหน้าต่างซ้อน" ใช้ข้อ 9 ดูสิ่งที่ตรวจเจอก่อนได้ และข้อ 10 สั่งล้างทันที

### ล้างแรม / ลดการใช้ CPU / รายงานสถานะ (เมนู 6 > ประสิทธิภาพ, เมนู 7)
**ล้างแรม (รูทเท่านั้น)** — ล้างแคชหน่วยความจำ (`drop_caches`) ทุก 30 นาที และ/หรือเมื่อ RAM ว่างต่ำกว่า 300 MB (ขั้นต่ำห่างกัน 1 นาที) แสดง RAM ว่างบนแผงสถานะ ตัวเลือก `am kill-all` ปิดอยู่เป็นค่าเริ่มต้น เพราะอาจปิดโคลนที่อยู่เบื้องหลัง

**ลดการใช้ CPU (เปิดเป็นค่าเริ่มต้น)**
- ตรวจทุกอินสแตนซ์พร้อมกันบนตารางเวลาเดียวกัน และใช้คำสั่งเชลล์ครั้งเดียวต่อรอบ (รายชื่อโปรเซส + หน้าจอ) แทนการเรียกต่อทีละอินสแตนซ์
- ลดความสำคัญโปรเซสของเครื่องมือ (`nice 10`) ให้เกมได้ CPU ก่อน (มีผลตอนเปิดโปรแกรม)
- เก็บผลตรวจสถานะเกมจาก Roblox API ไว้ 60 วินาที และรีเฟรชแผงสถานะทุก 2 วินาที (ปรับได้)
- เปิด "ตรวจว่าแอปอยู่หน้าจอ" เฉพาะเมื่อจำเป็น เพราะ `dumpsys` กิน CPU มากที่สุด

**รายงานสถานะ + ภาพหน้าจอเข้า Discord ทุก 10 นาที** — เมนู 7 ตั้งจำนวนนาที (0=ปิด) และสวิตช์ "รายงานสถานะ" ภาพหน้าจอแนบได้เฉพาะโหมดรูท (โหมดไม่รูทส่งเฉพาะข้อความ) เก็บภาพล่าสุด 20 รูปในโฟลเดอร์ `screenshots/`

ค่าใน `config.json`: `webhook.periodic_min` (10), `ram.interval_min` (30), `ram.min_free_mb` (300), `ram.kill_cached` (false), `performance.low_cpu` (true), `performance.ui_refresh_sec` (2)

### เรื่องคุกกี้ (cookie.txt)
- 1 บรรทัด / 1 บัญชี จับคู่กับอินสแตนซ์ที่ตรวจพบตามลำดับ (บรรทัดแรก = แพ็กเกจแรก) บรรทัดว่างและบรรทัดที่ขึ้นต้นด้วย `#` ถูกข้าม
- โปรแกรมแสดงคุกกี้แบบซ่อนเสมอ ไม่เขียนลงล็อก ไม่ส่งเข้า webhook ไม่เก็บใน `config.json`
- **ห้ามแชร์ไฟล์นี้หรือส่งต่อให้ใคร** — ใครได้คุกกี้ไปเข้าบัญชีคุณได้ทันที
- การใส่คุกกี้เขียนลงฐานข้อมูลคุกกี้ของแอป (`app_webview/.../Cookies`) ขึ้นกับเวอร์ชัน Roblox/โคลน ถ้าไม่สำเร็จให้ล็อกอินในแอปด้วยตัวเองหนึ่งครั้ง
